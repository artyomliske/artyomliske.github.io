# Артём Лиске — портфолио

Публичный статический сайт: **семь обязательств, тринадцать систем и подробные кейсы**. Он показывает не только интерфейсы, но и правила, проверки, эксплуатацию и границы автоматизации.

Сайт живёт на [artyomliske.ru](https://artyomliske.ru/); эта же ветка `main` публикуется на GitHub Pages как зеркало. Предыдущая версия сохранена в ветке `legacy-2026`, поэтому новую публикацию можно безопасно откатить через GitHub.

## Локальный просмотр

```bash
python3 -m http.server 8777
```

Затем откройте [http://localhost:8777](http://localhost:8777).

## Структура

| Путь | Назначение |
|---|---|
| `index.html` | Разметка страницы, интерактивные стенды и раскрытия кейсов. |
| `styles.css` | Типографика, адаптивная сетка, ленты, диалоги и доступные состояния фокуса. |
| `main.js` | Ленты, живые демонстрации, галереи и полноэкранный просмотр. |
| `fonts/` | Локальные подмножества Cormorant и Manrope. |
| `shots/` | Скриншоты систем на демонстрационных данных. |
| `og.jpg` | Превью ссылки для мессенджеров, 1200×630. |
